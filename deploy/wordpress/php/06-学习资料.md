# 06 · 学习资料（检索精选）

面向：会 H5/JS/CSS + iOS/鸿蒙，要补 **PHP + WordPress 主题**。

## 建议 2 周自学路径

**第 1 周**

1. 读完本目录 01–03  
2. 本地 `docker-compose.dev.yml` 起站，后台点一遍  
3. 只改 `main.css` 颜色，观察版本号与刷新  
4. 对照 Template Hierarchy 文档，画出 Holt 每个 URL 对应文件  

**第 2 周**

1. 读 `inc/cpt-work.php` + `single-work.php`，改一处文案  
2. 用浏览器打开 `/wp-json/wp/v2/work?per_page=2`，理解数据 JSON  
3. 读 04 部署流程，自己推一次仅 CSS 的 commit（或在分支演练）  
4. 浏览 05，想清楚「继续旁路 vs 新域名整包」适合你朋友站点的哪种

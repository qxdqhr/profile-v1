# 04 · 当前子应用（Holt 旁路）部署流程

说明：**现在这套**挂在 profile-v1 网关下的日常发布方式。  
目标环境：同域前缀 `https://qhr062.top/wp/holt/`。

## 1. 你改什么、CI 做什么

| 你改的文件 | CI / 服务器行为 |
|------------|-----------------|
| `app_wordpress/holt/**` | `deploy-web` **scp** 到 `/root/profile-v1/wordpress/holt/`（`WORDPRESS_CHANGED`） |
| `deploy/nginx/profile-platform.conf` | scp 后 reload 网关 nginx |
| `deploy/docker-compose.gateway.yml` | scp 后 `deploy-profile-v1.sh` / compose up |
| `app_wordpress/holt/data/*.json` | **不会**自动导入内容；需手动跑 import/sync workflow |
| `apps/*` Next 代码 | 走镜像 build（与 WP **无关**） |

触发：推送到 **`main`** → workflow `Build and Push Docker Images` → job **`deploy-web`**。

> 仅改 `deploy/**` 时 Next `build` 可能 skipped，但 `deploy-web` 仍应执行（workflow 已按此设计）。

## 2. 部署流水线（简化）

```
git push origin main
  → GitHub Actions
      →（可选）构建 Next 镜像
      → deploy-web:
           ssh 登录服务器
           scp compose / nginx / 主题 / ensure-*.sh
           注入 WP_* Secrets 到临时 env
           /root/profile-v1/deploy-profile-v1.sh
           ensure-wordpress-database.sh（幂等建库）
           compose up -d
           smoke-test-gateway.sh（含 /wp/holt/ 与主题 CSS）
```

服务器工作目录：`/root/profile-v1/`。

## 3. 需要的 GitHub Secrets

| Secret | 含义 |
|--------|------|
| `DEPLOY_SERVER_HOST` / `USERNAME` / `SSH_KEY` | 登录发布机 |
| `WP_HOLT_PUBLIC_URL` | 如 `https://qhr062.top/wp/holt` |
| `WP_MARIADB_ROOT_PASSWORD` | MariaDB root |
| `WP_DB_USER` / `WP_DB_PASSWORD` | WP 数据库用户 |

## 4. 运维手工脚本（内容 / 密码）

| 脚本 / Action | 用途 |
|----------------|------|
| `deploy/import-holt-bilibili-works.sh` | 用 JSON 导入/替换作品 |
| `deploy/sync-holt-work-meta-covers.sh` | 回填 meta + **分批**封面（建议串行、limit≤20） |
| `Reset Holt WordPress Admin Password` | workflow_dispatch 重置管理员密码 |
| `Import Holt Bilibili Works` | 远程执行导入 |

封面补导：**不要并行多开**，易打挂 PHP 容器。

## 5. 发布后自检

```bash
curl -sSI https://qhr062.top/wp/holt/ | head -5
curl -sSI https://qhr062.top/wp/holt/wp-admin/css/login.min.css | head -5
curl -sS  https://qhr062.top/wp/holt/wp-content/themes/holt-portfolio/assets/main.css | head -5
# 期望：页面 200；CSS Content-Type: text/css；:root 为浅色变量
```

后台能登录且 **不会**跳到 `https://qhr062.top/wp-admin`（缺前缀）。

## 6. 和 Next 子应用部署的差异（避免混淆）

| | Calendar 等 Next | Holt WordPress |
|--|------------------|----------------|
| 构建 | Docker 镜像 + 镜像仓库 | **官方镜像**，主要同步主题文件 |
| 进程 | Node | Apache + PHP |
| 路径 | `/calendar/` + basePath | `/wp/holt/` + WP_HOME |
| 登录 | 主站 better-auth | WP 自己的用户表 |
| 数据库 | Postgres | MariaDB `wp_holt` |

## 7. 日常改主题最短路径

```bash
# 1. 改主题
vim app_wordpress/holt/assets/main.css
# 2.  bump HOLT_THEME_VERSION
# 3. commit & push main
# 4. gh run watch <deploy-web run id>
# 5. 浏览器强刷
```

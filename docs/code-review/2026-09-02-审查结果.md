## 当前架构（落地后）

- 同域 nginx → 6 个 Next + WP/MariaDB；Godot 由平台 nginx alias `/var/www/games/<slug>/www/`。
- 鉴权只主站 `/api/auth`；本地跨端口打 `NEXT_PUBLIC_APP_URL`。
- `@profile/db` 仍聚合全平台 schema（一张 Postgres）。
- 主站 `/api/*`：middleware 默认要 session cookie；公开路径在 `src/lib/auth/public-api.ts`（方法敏感）。生产 `/api/examples/**` 404。
